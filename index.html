AgentGuard

Multi-Agent Security & Governance Platform for enterprise AI teams. Guardian middleware that sits between AI agents and their actions, intercepting and validating every operation before execution.

4-Layer Defense Architecture
  • L1 Input: Prompt injection detection (33-regex pre-filter + Azure Prompt Shields), harmful content filters, custom blocklists
  • L2 Output: PII detection, toxicity filtering, LLM-as-judge hallucination and groundedness check
  • L3 Tool Firewall: Entity recognition on tool args, contrastive indirect PI detection (MELON), 5 argument-aware guardrails, HITL/AITL approval gate
  • L4 RBAC + Behavioral: ABAC engine with ALLOW/DENY/ELEVATE, 5-signal anomaly detector (Z-score, Levenshtein, read-exfil chain, domain, entropy)
  • Covers OWASP Agentic AI Top 10: prompt injection, excessive agency, memory poisoning, insecure tool use, data exfiltration
  • Live dashboard with real-time OTel trace stream and audit log
